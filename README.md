# DiscordHelper

Небольшое приложение для Windows: снимок выбранного монитора, вопрос к модели и ответ в прозрачном окне. Минималистичный интерфейс со скруглениями и собственной верхней панелью. Поддерживает прямой OpenAI и OctavAPI через Responses API.

## Запуск

Скачай репозиторий через **Code → Download ZIP**, распакуй и запусти `dist/DiscordHelper.exe`. Установка не требуется; используется .NET Framework Windows. Закрой предыдущие версии, чтобы освободить глобальные горячие клавиши.

Открой «Настройки», выбери сервис и введи его API-ключ. Кнопка «Модели» получает доступные ID через `/v1/models`; ID также можно ввести вручную. Для снимков нужна модель с поддержкой изображений. Ключ не сохраняется приложением на диск. При переключении сервиса предыдущий ключ не переносится.

OctavAPI выбран по умолчанию, начальный ID модели — `gpt-6-luna`. Адрес: `https://octavapi.shop/v1/responses`. Для OpenAI: `https://api.openai.com/v1/responses`, начальная модель `gpt-4.1`. Получатель запроса отображается в настройках. Использование API оплачивается отдельно у выбранного сервиса.

При запуске выбирается дисплей с максимальным числом пикселей (ширина × высота); при равенстве — первый в списке. Экран можно выбрать вручную. Видимость окна регулируется от 40 до 100%, по умолчанию — 82%.

## Горячие клавиши

Сочетания редактируются в **Настройки → Горячие клавиши**. Нажми на поле действия, введи комбинацию с Ctrl, Alt или Shift и нажми **«Применить»**. Во время ввода глобальные действия отключены, включая удаление приложения. Одинаковые и занятые другой программой сочетания отклоняются; при неудачном применении прежние настройки сохраняются. **«По умолчанию»** заполняет стандартные значения — затем их тоже нужно применить.

Настройки сохраняются рядом с EXE в `hotkeys.json` и загружаются при следующем запуске. Этот файл содержит только сочетания, без API-ключа, снимков и ответов. Если папка недоступна для записи, приложение сообщает об ошибке и сохраняет прежние сочетания. При повреждённом файле используются стандартные значения.

Стандартные сочетания:

| Сочетание | Действие |
|---|---|
| Ctrl + ↑ | Новый снимок и сразу отправка вместе с вопросом |
| Ctrl + ↓ | Только новый снимок для предпросмотра |
| Ctrl + → | Отправить текущий снимок и вопрос; без снимка — только текст |
| Ctrl + Shift + ↓ | Показать или скрыть окно, вернуть после сворачивания |
| Ctrl + Shift + ↑ | Очистить сеанс, закрыться и удалить запущенную копию приложения |

**Сочетание удаления (по умолчанию Ctrl+Shift+↑) удаляет файлы без дополнительного подтверждения.** Сначала очищаются поля ключа, вопроса и ответа, освобождается снимок и отменяется локальное ожидание запроса. Буфер обмена очищается только если в нём остался текст, скопированный приложением. После закрытия скрытый процесс PowerShell удаляет точный запущенный EXE, его инструкцию `dist/README.md` и собственный `hotkeys.json`, проверяя контрольные суммы. Папка удаляется только если пустая. Соседние и изменённые файлы сохраняются. Для повторного запуска потребуется восстановить EXE из репозитория или пересобрать его.

Эта функция не удаляет исходник, старые копии, системные журналы Windows, историю буфера обмена, переменные окружения с ключами и данные на серверах. Отмена ожидания не отменяет уже выполненную обработку на сервере.

## Окно и захват

Значка на панели задач нет. Окно можно перетаскивать за верхнюю панель и менять размер за края. Собственные кнопки сворачивают, разворачивают и закрывают окно.

Скрытие окна из захвата включено по умолчанию через Windows `SetWindowDisplayAffinity` / `WDA_EXCLUDEFROMCAPTURE`. Полное исключение поддерживается Windows 10 версии 2004 и новее. Работу необходимо проверить в нужной программе демонстрации на стороне зрителя: механизм не гарантирует скрытие при любом способе захвата.

Снимок хранится в памяти и включает весь выбранный монитор. Ctrl+↑ отправляет его сразу; для проверки предпросмотра используй раздельные снимок и отправку. Реальные ключи, снимки и ответы в этот репозиторий не включены.

## Сборка

В PowerShell из корня репозитория:

```powershell
.\build.ps1
```

Скрипт использует компилятор C# из .NET Framework Windows и создаёт `dist/DiscordHelper.exe`. Сторонние библиотеки не требуются.

Исходник: `src/DiscordHelper.cs`. Проверены компиляция, API-адреса и формат запросов на локальных данных, управление окном, очистка сеанса, исключение из захвата и удаление тестовой копии после выхода. Реальные запросы с ключом и совместимость с внешними трансляциями отдельно не подтверждены.

Документация: [OctavAPI](https://octavapi.shop/docs/manual?tool=api), [Windows capture exclusion](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity).
